# TankSense_IOT

## ¿Qué hace?
TankSense mide el nivel de agua de un tanque y muestra el resultado en una página web.

## ¿Cómo lo hace?
Un sensor ultrasónico colocado en la parte superior del tanque mide la distancia hasta la superficie del agua. Un Raspberry Pi 4 lee esa distancia, calcula el nivel del agua y envía la información a la página.


Sensor ultrasónico → Raspberry Pi 4 → Cálculo del nivel → Página web → Usuario


## ¿Por qué lo hace?
Para conocer cuánta agua queda en un tanque sin tener que abrirlo ni revisarlo manualmente, logrando una mejor administración del agua y menos posibilidades de quedarse sin suministro.

## Proyecto grupal
Este proyecto es una tarea grupal del curso de Internet of Things.
